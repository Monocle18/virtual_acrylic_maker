# virtual-acrylic-maker（虚拟亚克力砖生成器）

一款零依赖、纯前端单文件运行的 **3D 虚拟亚克力砖实时预览与无缝循环 GIF 生成工具**。无需安装 Python、无需后端服务器、不使用 AI 重绘，100% 保留原图细节，所有渲染与 GIF 编码均在浏览器本地完成。

## 核心特性

- **开箱即用，单文件离线运行**：整套应用封装在单个 `virtual-acrylic-maker.html` 文件中，双击用现代浏览器打开即可使用，图片全程不上传服务器。
- **WebGL GPU 实时 60fps 预览**：采用 WebGL1 片元着色器与正交 3D 透视矩阵渲染，支持在导出前实时调节参数、无延迟所见即所得。
- **双交互预览模式**：
  - **自动摇晃循环**：48 帧无缝 3D 轨道倾摆（Y 轴 ±17.5°、X 轴 ±10.5°、Z 轴 ±2.2°）配轻柔上下悬浮。
  - **鼠标拖拽指定角度**：按住画布自由旋转观察任意侧面的实体厚度与全息光纹，并支持一键回正。
- **丰富的材质与全息效果**：
  - **全息底纹风格**：宇宙星斑（光球微星）、放射太阳纹（旋转光束）、水波丝绸纹（流动缎面），以及「无底纹效果（纯净原图）」。
  - **金属卡边与烫金色调**：幻彩紫金、鎏金色、冰银色，以及「无金属边（哑光纯色卡边）」。
  - **实体质感细节**：圆角抗锯齿 SDF、8 层立体拉丝厚度切片、Sobel 线稿微浮雕高光、斜向玻璃扫光、呼吸氛围光晕、反向位移投影、高光锚定 4 芒星闪与前后景无缝循环粒子。
- **自由分辨率与透明 PNG 兼容**：
  - 提供 `460px` / `800px` / `1080px` 三档快捷预设，并支持无上限自定义画布宽高与内部亚克力砖尺寸（支持锁定原图宽高比）。
  - 自动将透明底 PNG 柔和合成到珍珠白卡底，避免透明区变黑。
- **内置纯 JS GIF89a 编码器**：支持一键导出 48 帧（25fps）无缝循环 GIF，带实时进度条与随时取消功能；同时支持一键保存当前角度高清 PNG 静图。

## 快速开始

### 本地直接使用
1. 下载本仓库中的 `virtual-acrylic-maker.html`（或直接 `git clone` 本仓库）。
2. 双击 `virtual-acrylic-maker.html`，使用 Chrome / Edge / Firefox / Safari 等现代浏览器打开。
3. 点击预览区或将本地图片（JPG / PNG / WebP）直接拖入窗口，调节效果后点击导出即可。

## 参数与导出参考

| 预设档位 | 画布参考宽度 | 适用场景 | 说明 |
| :--- | :--- | :--- | :--- |
| **标准 460** | `460px` | 聊天表情、社交平台轻量分享 | 导出极快，体积小巧 |
| **高清 800** | `800px` | 日常展示、个人收藏 | 清晰度与体积均衡 |
| **超清 1080** | `1080px` | 高清细节展示 | 画面锐利，体积相应增大 |
| **自定义尺寸** | 自由输入 | 头像、竖屏壁纸等定制比例 | 支持单独调整画布与内部砖体像素 |

> **注意事项**：自定义画布与砖体分辨率未设置硬性上限。若输入过大的像素尺寸（例如超过 2000px），可能会显著延长 GIF 编码耗时，并存在导致浏览器标签页内存吃满而卡死或崩溃的风险，请结合自身设备性能合理设置。

## 技术实现概览

| 模块 | 实现方式 |
| :--- | :--- |
| **3D 几何与着色** | 原生 WebGL1 + GLSL ES 1.0 片元着色器（圆角 SDF、8 层 `+Z` 厚度切片、正交旋转矩阵、Sobel 邻域梯度浮雕） |
| **氛围与空间合成** | HTML5 Canvas 2D（径向暗角背景、呼吸光晕、模糊悬浮阴影、4 芒星闪与整数频率无缝粒子） |
| **GIF 压缩编码** | 内置零依赖纯 JavaScript GIF89a 编码器（Median Cut 256 色量化 + 5-bit RGB LUT + 误差死区抑制 Floyd-Steinberg 抖动 + 变长 LZW 压缩） |
| **界面样式** | Tailwind CSS（CDN 引入，代码内已按 7 大模块编写详尽中文注释，便于二次开发与魔改） |
